# About Me Website

This project is a simple "About Me" website created using HTML and CSS. It includes a main HTML document (`index.html`) that outlines the structure of the webpage, and a CSS file (`styles.css`) that provides basic styling to enhance the visual presentation.

## Files

- **index.html**: The main HTML document for the "About Me" website. It contains sections for the title, a brief introduction, and additional information about the user.
  
- **styles.css**: The CSS file that contains basic styling for the website, defining styles for the body, headings, paragraphs, and other elements.
